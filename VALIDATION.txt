MediaBack 0.4.3 - local verification / локальная проверка

RU

Исправлены обновление обложки без смены названия, отмена устаревших чтений,
очистка старого изображения перед загрузкой нового и ограниченные повторные
чтения задержанной обложки. Кэш изолирован по экземплярам медиасессий.
Постоянного частого опроса нет: три повтора после смены трека и прежняя
минутная проверка состояния. Одинаковые изображения переиспользуются.

Всплывающие подсказки удалены с панели, настроек и диалогов. Названия
элементов для экранного диктора и сведения об ошибке цвета сохранены.

26 новых проверок прошли. В общем прогоне 190 успешных проверок и пять
сбоев тестов получения фокуса Windows. Те же пять сбоев воспроизвелись
на неизменённой 0.4.2 в этой среде. Игровой код в обновлении не менялся;
полностью пройденный тест фокуса здесь не заявляется.

Переводы: 221 ключ RU/EN, 210 используемых ссылок, параметры совпадают.
Сборка приложения и MSI завершилась успешно. Установщик проверен Microsoft
Defender: угроз не обнаружено. Это не независимый аудит безопасности.

Проверка задержанных обложек использует управляемые последовательности
метаданных/изображений, быстрые смены трека, отмену чтения из другого потока,
отсутствующую картинку и одинаковые обложки альбома. Реальное воспроизведение
пользователя тестом не переключалось. Если сам плеер не отдаёт актуальную
обложку Windows, приложение не может восстановить её из названия трека.

Проверено обновление установленной 0.4.2 до 0.4.3: код MSI 0, EXE совпал
с проверенной сборкой, файл пользовательских настроек не изменился.
Приложение запущено обратно в фоне. Полное удаление/переустановка 0.4.3
не выполнялись. Подпись издателя отсутствует.

EN

Fixed artwork-only updates, obsolete async reads, previous-track image reuse
and delayed thumbnail refresh. Artwork state is isolated per media-session
instance. Three bounded follow-ups run around track changes; the existing
minute watchdog remains. Matching decoded images are reused.

Hover tooltips were removed from the flyout, settings and dialogs. Accessibility
names and color-validation help for screen readers remain available.

All 26 new checks passed. The full run had 190 passing checks and five
foreground-focus test failures, reproduced unchanged on 0.4.2 in this environment.
Game interaction code was not modified. A fully passing focus test is not claimed.

Localization: 221 RU/EN keys, 210 references, matching placeholders.
Application and MSI builds succeeded. Microsoft Defender found no threats in
the installer. This is not an independent security audit.

Artwork tests use controlled delayed image/metadata sequences, rapid skips,
background-thread cancellation, missing images and shared album art. They do
not switch the user's current playback. If a player does not supply the current
image to Windows, the app cannot reconstruct it from the track title.

The installed 0.4.2 to 0.4.3 upgrade succeeded; the installed EXE matched the
tested build and the settings file was unchanged. Background operation resumed.
A full uninstall/reinstall was not performed. The MSI is unsigned.
